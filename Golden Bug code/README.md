# GoldenBugEvents

Aplicação em Vue.js para encontrar eventos em Belém.

## Tecnologias

- Vue 3, Vue Router e Bootstrap

## Páginas

- Início, Eventos, Evento (`/evento/:id`), Feriados e Sobre (mais a página 404)

## API utilizada

- **API:** BrasilAPI (feriados nacionais)
- **Endpoint:** `https://brasilapi.com.br/api/feriados/v1/2026`
- **Método:** GET
